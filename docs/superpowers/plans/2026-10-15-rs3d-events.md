## Global Constraints

- Defaults (copied from the user's rsudp settings): `enabled=True`, `channel="EHZ"`, `sta=6.0`, `lta=30.0`, `on=3.95`, `reset=0.9`, `highpass=0.8`, `lowpass=9.0`. All editable in Settings.
- An event starts when the ratio rises **above** `on` and ends when it falls **below** `reset`. `on_start(start, ratio)` fires at the start, `on_event(Event)` at the end.
- The detector is silent while the LTA window fills (first `lta` seconds after startup or after a gap longer than `1.5` sample intervals). Only the configured channel is analysed.
- `Event` fields: `start`, `end` (epoch seconds), `peak_ratio`, `peak_amplitude` (counts), `channel`, `source` (`"live"` or `"scan"`).
- `events.jsonl` lives in the data folder, one JSON object per line. A corrupt line is skipped and counted, never fatal. `replace_scan_events` removes only `source == "scan"` events and never live ones. Where a live and a scan event overlap, only the live one is listed.
- A detector failure must never stop `LiveStream`.
- Invalid settings (LTA not larger than STA, reset not below on, band-pass outside 0 to Nyquist) are rejected with a message; the previous values stay active.
- If `events.jsonl` cannot be written, the banner and in-memory list still work and the Status page shows a warning.
- UI text goes through `app/strings.py` (`help/en.toml`). English first. Compact UI with (?) help icons.

## Review Focus

Failure modes the spec implies but a first implementation would not test. Each has a pinning test in the task named.

1. **Flat or dead sensor** (all zeros, or a constant offset): LTA is 0, so the ratio must be 0, with no NaN, no divide warning, no event. Task 1 `test_flat_data_gives_no_event`.
2. **Overlapping or re-sent packets** (SeedLink reconnect re-delivers a chunk that starts before the expected next sample): must not crash, must not invent an event; it counts as a gap and restarts warm-up. Task 1 `test_resent_packet_is_safe`.
3. **Event still open at the end of the data** (a day that ends mid-shaking, or live data that stops): the event is closed at the last sample, not lost. Task 1 `test_detect_closes_event_at_end_of_data`.
4. **Hand-edited or corrupt `settings.toml`** (`lta` smaller than `sta`, a string where a number belongs): the app still starts with defaults. Task 4 `test_bad_saved_event_settings_fall_back`.
5. **Settings change or switch-off while an event is open**: the event is closed and logged, then the new detector starts clean (warm-up again). Task 4 `test_settings_change_closes_open_event`.
6. **Event near midnight when scanning a day** (shaking in the first seconds of a day, whose LTA window lives in the previous day's file): the scan loads the previous `lta` seconds as warm-up and keeps only events that start inside the day. Task 3 `test_scan_day_uses_previous_day_for_warmup`.

```python
"""STA/LTA event detection, shared by the live stream and the scan of downloaded days."""

from __future__ import annotations

import threading
from dataclasses import dataclass
from typing import Callable

import numpy as np
from obspy import Stream, Trace
from scipy.signal import butter, lfilter, sosfilt, sosfilt_zi

GAP_TOLERANCE = 1.5  # samples: a start further than this from the expected next sample is a gap


@dataclass
class EventSettings:
    enabled: bool = True
    channel: str = "EHZ"
    sta: float = 6.0
    lta: float = 30.0
    on: float = 3.95
    reset: float = 0.9
    highpass: float = 0.8
    lowpass: float = 9.0


@dataclass
class Event:
    start: float  # epoch seconds
    end: float
    peak_ratio: float
    peak_amplitude: float  # counts, after the band-pass
    channel: str
    source: str  # "live" or "scan"


def validate_settings(s: EventSettings, nyquist: float = 50.0) -> str:
    """'' when the settings can be used, else the reason they cannot."""
    if s.channel not in ("EHZ", "EHN", "EHE"):
        return "Channel must be EHZ, EHN or EHE."
    if s.sta <= 0:
        return "STA must be positive."
    if s.lta <= s.sta:
        return "LTA must be longer than STA."
    if s.reset >= s.on:
        return "Reset must be lower than On."
    if s.reset <= 0:
        return "Reset must be positive."
    if not 0 < s.highpass < s.lowpass < nyquist:
        return f"Band-pass must satisfy 0 < high-pass < low-pass < {nyquist:g} Hz."
    return ""


class EventDetector:
    """Feed it traces in time order. Calls `on_start(start, ratio)` when an event begins and
    `on_event(Event)` when it ends. Silent while the LTA window fills after a start or a gap."""

    def __init__(self, settings: EventSettings, on_event: Callable[[Event], None],
                 on_start: Callable[[float, float], None] | None = None, source: str = "live") -> None:
        self.settings = settings
        self._on_event = on_event
        self._on_start = on_start
        self._source = source
        self._open: dict | None = None
        self._last_t: float | None = None
        self._lock = threading.RLock()  # the live thread feeds while the UI thread may flush
        self._reset()

    @property
    def active(self) -> bool:
        return self._open is not None

    def _reset(self) -> None:
        self._rate = 0.0
        self._next: float | None = None
        self._seen = 0

    def _begin(self, rate: float, first: float) -> None:
        s = self.settings
        self._rate = rate
        self._seen = 0
        self._sos = butter(2, [s.highpass, min(s.lowpass, 0.45 * rate)], btype="bandpass", fs=rate, output="sos")
        self._bp_zi = sosfilt_zi(self._sos) * first  # start settled on the first sample: no step transient
        self._a_sta = 1.0 - 1.0 / (s.sta * rate)
        self._a_lta = 1.0 - 1.0 / (s.lta * rate)
        self._sta_zi = np.zeros(1)
        self._lta_zi = np.zeros(1)

    def feed(self, tr: Trace) -> None:
        with self._lock:
            self._feed(tr)

    def _feed(self, tr: Trace) -> None:
        s = self.settings
        if not s.enabled or tr.stats.channel != s.channel or tr.stats.npts == 0:
            return
        rate = float(tr.stats.sampling_rate)
        start = tr.stats.starttime.timestamp
        x = np.asarray(tr.data, dtype=float)
        if self._next is None or rate != self._rate or abs(start - self._next) > GAP_TOLERANCE / rate:
            self.flush()
            self._begin(rate, x[0])
        y, self._bp_zi = sosfilt(self._sos, x, zi=self._bp_zi)
        n = len(x)
        k = self._seen + np.arange(1, n + 1)
        sta_raw, self._sta_zi = lfilter([1 - self._a_sta], [1, -self._a_sta], y * y, zi=self._sta_zi)
        lta_raw, self._lta_zi = lfilter([1 - self._a_lta], [1, -self._a_lta], y * y, zi=self._lta_zi)
        sta = sta_raw / (1 - self._a_sta ** k)  # bias-corrected while the windows fill
        lta = lta_raw / (1 - self._a_lta ** k)
        ratio = np.divide(sta, lta, out=np.zeros(n), where=lta > 0)
        ratio[k < s.lta * rate] = 0.0  # warm-up: never trigger
        self._seen += n
        self._scan(ratio, y, start, rate)
        self._next = start + n / rate
        self._last_t = start + (n - 1) / rate

    def _scan(self, ratio: np.ndarray, y: np.ndarray, start: float, rate: float) -> None:
        s, n, i = self.settings, len(ratio), 0
        above, below = ratio > s.on, ratio < s.reset
        while i < n:
            if self._open is None:
                j = int(np.argmax(above[i:])) + i
                if not above[j]:
                    return
                self._open = {"start": start + j / rate, "ratio": float(ratio[j]), "amp": 0.0}
                if self._on_start:
                    self._on_start(self._open["start"], self._open["ratio"])
                i = j
            k = int(np.argmax(below[i:])) + i
            stop = k if below[k] else n
            if stop > i:
                self._open["ratio"] = max(self._open["ratio"], float(ratio[i:stop].max()))
                self._open["amp"] = max(self._open["amp"], float(np.abs(y[i:stop]).max()))
            if not below[k]:
                return
            self._close(start + k / rate)
            i = k + 1

    def _close(self, end: float | None) -> None:
        if self._open is None:
            return
        o, self._open = self._open, None
        self._on_event(Event(o["start"], end if end is not None else o["start"], o["ratio"], o["amp"],
                             self.settings.channel, self._source))

    def flush(self) -> None:
        """Close an event in progress at the last sample seen (end of data, a gap, new settings)."""
        with self._lock:
            self._close(self._last_t)


def detect(data: Trace | Stream, settings: EventSettings) -> list[Event]:
    """Events in recorded data. Same algorithm as the live detector."""
    traces = [data] if isinstance(data, Trace) else sorted(data, key=lambda t: t.stats.starttime)
    out: list[Event] = []
    detector = EventDetector(settings, out.append, source="scan")
    for tr in traces:
        detector.feed(tr)
    detector.flush()
    return out
```

```python
"""Event log: one JSON object per line in events.jsonl."""

from __future__ import annotations

import json
import os
import threading
from dataclasses import asdict
from pathlib import Path

from rs3d.core.events import Event


class EventStore:
    def __init__(self, path: Path) -> None:
        self.path = Path(path)
        self.error = ""  # why the last write failed; "" when writes work
        self.skipped = 0  # corrupt lines seen by the last read
        self._lock = threading.Lock()

    def append(self, event: Event) -> bool:
        """Add one event. False (and `error` set) when the file cannot be written."""
        line = json.dumps(asdict(event)) + "\n"
        with self._lock:
            try:
                self.path.parent.mkdir(parents=True, exist_ok=True)
                with open(self.path, "a", encoding="utf-8") as f:
                    f.write(line)  # one write call per line keeps appends whole
            except OSError as exc:
                self.error = str(exc)
                return False
            self.error = ""
            return True

    def _read(self) -> list[Event]:
        out: list[Event] = []
        self.skipped = 0
        try:
            text = self.path.read_text(encoding="utf-8")
        except FileNotFoundError:
            return out
        except OSError as exc:
            self.error = str(exc)
            return out
        for line in text.splitlines():
            if not line.strip():
                continue
            try:
                out.append(Event(**json.loads(line)))
            except (ValueError, TypeError):
                self.skipped += 1
        return out

    @staticmethod
    def _listed(events: list[Event]) -> list[Event]:
        """Sorted by start; a scan event that overlaps a live event is dropped."""
        live = [e for e in events if e.source == "live"]
        keep = [e for e in events
                if e.source == "live" or not any(e.start <= v.end and v.start <= e.end for v in live)]
        return sorted(keep, key=lambda e: e.start)

    def events_between(self, t0: float, t1: float) -> list[Event]:
        """Events that overlap [t0, t1]."""
        with self._lock:
            events = self._read()
        return [e for e in self._listed(events) if e.start <= t1 and e.end >= t0]

    def latest(self, n: int) -> list[Event]:
        """The n most recent events, newest first."""
        with self._lock:
            events = self._read()
        return self._listed(events)[::-1][:n]

    def replace_scan_events(self, t0: float, t1: float, events: list[Event]) -> bool:
        """Swap the scan events that start in [t0, t1) for `events`. Live events stay."""
        with self._lock:
            kept = [e for e in self._read() if not (e.source == "scan" and t0 <= e.start < t1)]
            lines = "".join(json.dumps(asdict(e)) + "\n" for e in kept + list(events))
            tmp = self.path.with_name(self.path.name + ".tmp")
            try:
                self.path.parent.mkdir(parents=True, exist_ok=True)
                tmp.write_text(lines, encoding="utf-8")
                os.replace(tmp, self.path)
            except OSError as exc:
                self.error = str(exc)
                return False
            self.error = ""
            return True
```

```python
"""Run the detector over stored days and keep the result in the event log."""

from __future__ import annotations

from datetime import date, timedelta

from obspy import UTCDateTime

from rs3d.core.events import EventSettings, detect
from rs3d.core.events_store import EventStore
from rs3d.core.models import Selection
from rs3d.core.store import Store


def days_between(first: date, last: date) -> list[date]:
    """Every date from `first` to `last`, both included."""
    return [first + timedelta(days=i) for i in range((last - first).days + 1)]


def scan_day(store: Store, events: EventStore, settings: EventSettings, net: str, sta: str, loc: str,
             day: date) -> int:
    """Detect events on one UTC day and replace that day's scan events in the log. Returns the count.

    The previous `lta` seconds are loaded as warm-up so shaking right after midnight is not lost; only events
    that start inside the day are kept.
    """
    t0 = UTCDateTime(day.year, day.month, day.day)
    t1 = t0 + 86400
    sel = Selection(net, sta, loc, t0 - settings.lta, t1, channels=(settings.channel,))
    found = [e for e in detect(store.load(sel), settings) if t0.timestamp <= e.start < t1.timestamp]
    events.replace_scan_events(t0.timestamp, t1.timestamp, found)
    return len(found)
```

def _clean_event_settings(raw) -> EventSettings:
    """Saved event settings; any missing or wrongly typed value falls back to its default, and a set that
    fails validation (e.g. a hand-edited LTA shorter than STA) falls back entirely."""
    defaults = EventSettings()
    if not isinstance(raw, dict):
        return defaults
    values = {}
    for f in fields(EventSettings):
        default, value = getattr(defaults, f.name), raw.get(f.name)
        if isinstance(default, bool):
            ok = isinstance(value, bool)
        elif isinstance(default, str):
            ok = isinstance(value, str)
        else:
            ok = isinstance(value, (int, float)) and not isinstance(value, bool)
        values[f.name] = (float(value) if isinstance(default, float) else value) if ok else default
    settings = EventSettings(**values)
    return settings if validate_settings(settings) == "" else defaults

    """markArea pairs in the helicorder's own coordinates (x = minutes in the row, y = row index ± 0.5)."""
    out: list = []
